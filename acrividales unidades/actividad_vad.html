Contexto Profesional Auténtico

Ustedes han sido contratados como Analistas de Calidad por una empresa que fabrica botellas térmicas reutilizables.

Durante el proceso de producción se mide el diámetro de cierre de cada botella. La especificación técnica establece que una botella será considerada defectuosa si su diámetro se encuentra fuera del intervalo:

49.80 mm ≤ Diámetro ≤ 50.20 mm

La empresa les entrega una muestra correspondiente a los últimos 100 productos fabricados, incluyendo las mediciones registradas.

La gerencia desea tomar decisiones sobre la calidad de producción y necesita conocer el comportamiento probabilístico de los defectos.

Propósito de Aprendizaje

Al finalizar la actividad, el estudiante será capaz de analizar datos reales de calidad, identificar productos defectuosos, modelar el número de defectos mediante variables aleatorias discretas y seleccionar una distribución probabilística apropiada para describir el fenómeno observado.

Competencias Evaluadas

  1. Recolectar y sistematizar datos utilizando métodos adecuados para construir tablas de frecuencias y representaciones gráficas pertinentes según el tipo de variable.
  2. Calcular e interpretar medidas estadísticas para describir y analizar conjuntos de datos.
  3. Modelar situaciones aleatorias aplicando conceptos de probabilidad y distribuciones discretas.
  4. Emplear herramientas digitales para realizar análisis exploratorios y comunicar resultados.

Situación Problema

La gerencia desea implementar controles de calidad por lotes de 10 botellas.

Antes de hacerlo, necesita responder la siguiente pregunta:

¿Cómo se comporta la variable aleatoria "Número de productos defectuosos en un lote de 10 botellas"?

La respuesta deberá estar sustentada mediante análisis estadístico y modelos probabilísticos.

Fase 1. Exploración y Clasificación de los Datos

Actividades

  1. Importar la base de datos en Excel, Jamovi, R, SPSS, Python o software similar.
  2. Revisar las 100 mediciones suministradas.
  3. Crear una nueva variable llamada: Estado del Producto.
    • Defectuoso = 1
    • No defectuoso = 0
  4. Clasificar cada producto según el criterio establecido.
  5. Calcular el número total de productos defectuosos.
  6. Calcular el porcentaje de defectos.

Entregables

  • Tabla de datos clasificada.
  • Porcentaje de defectos.
  • Captura del procedimiento realizado.

Fase 2. Análisis Descriptivo

Variable de Estudio

Número de defectos observados.

Actividades

  1. Construir tabla de frecuencias.
  2. Construir gráfico adecuado:
    • Gráfico de barras.
    • Diagrama de Pareto (opcional).
  3. Calcular:
    • Media.
    • Moda.
    • Varianza.
    • Desviación estándar.
  4. Interpretar cada medida dentro del contexto de calidad.

Preguntas de Reflexión

  • ¿Qué tan frecuente es encontrar defectos?
  • ¿La producción parece estable?
  • ¿Existen evidencias de problemas de calidad?
  • ¿La cantidad de defectos observada es preocupante para la empresa?

Fase 3. Construcción de la Variable Aleatoria

Definición

Sea:

X = Número de productos defectuosos encontrados en un lote de 10 botellas.

Actividades

  1. Identificar el experimento aleatorio.
  2. Determinar los posibles valores de X.
  3. Construir el espacio de valores posibles de la variable.
  4. Explicar por qué X es una variable aleatoria discreta.

Fase 4. Modelamiento Probabilístico

Pregunta Central

¿Qué distribución probabilística modela mejor la variable “Número de productos defectuosos en un lote de 10 productos”?

Actividades

  1. Estimar la probabilidad de defecto utilizando la muestra real.
  2. Evaluar si el proceso puede modelarse mediante una distribución Binomial.
  3. Determinar:
    • n
    • p
    • Media teórica
    • Varianza teórica
  4. Construir la distribución de probabilidad de X.
  5. Representar gráficamente la distribución.
  6. Interpretar:
    • P(X=0)
    • P(X=1)
    • P(X=2)
    • P(X≥3)

Fase 5. Comparación entre Modelos

Investigue y argumente cuál de las siguientes distribuciones podría utilizarse en contextos de control de calidad:

  • Bernoulli.
  • Binomial.
  • Poisson.
  • Hipergeométrica.
  • Binomial Negativa.

Explique cuándo sería apropiada cada una.

Fase 6. Storytelling Estadístico

Rol Profesional

Usted es el analista responsable de presentar los resultados al Director de Producción.

Pregunta guía

¿La calidad actual de producción es suficientemente buena para vender los lotes sin aumentar los controles de inspección?

La presentación debe incluir

  1. Introducción al problema.
  2. Descripción de los datos.
  3. Análisis descriptivo.
  4. Modelo probabilístico seleccionado.
  5. Interpretación de probabilidades.
  6. Conclusión ejecutiva.
  7. Recomendaciones para la empresa.
