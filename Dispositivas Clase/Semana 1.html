Introducción a Sistemas de Ecuaciones

  • Objetivo: Resolver sistemas lineales 2x2.
  • Competencia: Modelar matemáticamente problemas reales.

Reto Inicial

  • Una empresa fabrica dos productos distintos.
  • ¿Qué variables desconocemos?
  • ¿Qué restricciones existen?
  • ¿Cómo comprobarían una respuesta?

Del problema al modelo matemático

x = Cantidad producto 1
y = Cantidad producto 2
Problema ➔ Variables ➔ Ecuaciones

¿Qué es una solución?

  • Satisface ambas ecuaciones simultáneamente.
  • Es el punto de intersección.

Sistemas n×n

  • Tienen "n" ecuaciones.
  • Tienen "n" variables desconocidas.
  • Se modelan con matrices (Ax = b).
  • Mayor complejidad requiere software.
a₁₁x₁ + ... + a₁ₙxₙ = b₁
...
aₙ₁x₁ + ... + aₙₙxₙ = bₙ

Método de Sustitución

  • Despejar una variable.
  • Sustituir en la otra ecuación.
  • Resolver la ecuación resultante.
  • Encontrar la otra variable.
  • Verificar los resultados obtenidos.

Actividad Colaborativa

  • Formen equipos de trabajo.
  • Planteen el sistema matemático.
  • Resuélvanlo paso a paso.
  • Comparen resultados obtenidos.
  • Validen en herramienta web.

Nuevo Desafío

  • Caso Finanzas: Inversión de capital.
