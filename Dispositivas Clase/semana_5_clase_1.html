El Reto: El Caos Masivo

Imagina que tenemos una base de datos con 1,000 registros numéricos continuos (por ejemplo, salarios exactos con centavos).

El Problema

Si hacemos una tabla de frecuencias tradicional como las de la semana 2, tendríamos casi 1,000 filas distintas.

¿Cómo le presentamos esto a una junta directiva sin que se queden dormidos?

Hipótesis: Agrupando el Caos

Propuestas de Agrupación

¿Cómo agruparían ustedes estos 1,000 datos?

  • ¿Por rangos cerrados? (Ej. "De $1000 a $2000").
  • ¿Intervalos de $500?

La gran pregunta estadística:

¿Cuántos grupos son muy pocos y cuántos son demasiados?

Barras vs. Histogramas

Gráfico de Barras

  • Se usa para variables categóricas o cualitativas.
  • Las barras están separadas entre sí, indicando que no hay continuidad entre las categorías (Ej. Colores, Ciudades).

Histograma

  • Se usa para variables numéricas continuas agrupadas en intervalos.
  • Las barras están pegadas, mostrando la continuidad matemática de los datos a lo largo de un eje numérico.

La Regla de Sturges

Es una regla matemática empírica para determinar el número ideal de intervalos (clases) al construir un histograma y agrupar datos.

1. Número de Intervalos ($k$)

$$k = 1 + 3.322 \log_{10}(n)$$

Donde $n$ es la cantidad total de datos.
Nota: El valor de $k$ debe redondearse al entero más cercano.

2. Amplitud del Intervalo ($A$)

$$A = \frac{Rango}{k}$$

Define el "ancho" numérico que tendrá cada barra en nuestro histograma.

Actividad Guiada: Construcción

Dinámica en Grupos de 3: Utilicen el set de 50 datos entregado por el profesor para realizar los siguientes cálculos paso a paso.

  1. Calcular el número óptimo de intervalos ($k$) usando Sturges.
  2. Calcular la amplitud ($A$) de clase.
  3. Construir los intervalos (Límite Inferior - Límite Superior).
  4. Realizar el conteo rápido de frecuencias para la primera clase.
