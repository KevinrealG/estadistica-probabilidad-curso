## **Paso 3 – Cálculo para datos univariados**

Para cada variable **cuantitativa**:

1. Seleccione una columna.
2. Calcule en celdas separadas:
    - **MEDIA** → fórmula: =PROMEDIO(rango)
    - **MEDIANA** → =MEDIANA(rango)
    - **MODA** → =MODA.UNO(rango)
    - **RANGO** → =MAX(rango)-MIN(rango)
    - **VARIANZA** → =VAR.P(rango)
    - **DESV. ESTÁNDAR** → =DESVEST.P(rango)
    - **CUARTIL 1** → =CUARTIL.INC(rango,1)
    - **CUARTIL 3** → =CUARTIL.INC(rango,3)
    - **PERCENTIL 90** → =PERCENTIL.INC(rango,0.9)
3. Registre todos los valores calculados en una tabla en excel
