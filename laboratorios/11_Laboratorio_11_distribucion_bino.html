"Auditoría Algorítmica de Operaciones y Riesgo"

Eres el analista principal de datos asignado a auditar una planta automatizada de comercio electrónico. Debido a que cada analista audita una línea de producción distinta, tus parámetros operativos dependen exclusivamente de los últimos 4 dígitos de tu código estudiantil. Analizarás la conversión de pedidos de tu línea de producción:

  1. Control de Conversión (Binomial): La planta procesa un lote de pedidos y considera éxito cada envío entregado correctamente; cada pedido tiene la misma probabilidad de éxito y se analiza de forma independiente. Con los parámetros individuales generados a partir de tu código estudiantil ($n$ pedidos y probabilidad de éxito $p$), modela el número de entregas exitosas. Calcula la probabilidad de obtener exactamente una cantidad determinada de éxitos y la de alcanzar o superar una meta operativa, y usa la media esperada para estimar cuántos pedidos del lote llegarían correctamente a su destino.

Código Base para el Estudiante

Cada estudiante debe ejecutar esta celda inicial en Google Colab ingresando los últimos 4 dígitos de su código estudiantil para generar su entorno único:

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import binom

# ==========================================================
# PASO CRÍTICO: INGRESA LOS ÚLTIMOS 4 DÍGITOS DE TU CÓDIGO
# ==========================================================
mi_codigo = 4829  # <-- Reemplaza con tus últimos 4 dígitos
np.random.seed(mi_codigo)

# Generación automática de tus parámetros binomiales
n_binom = 12 + (mi_codigo % 8)                  # Ensayos entre 12 y 19
p_exito = round(0.30 + (mi_codigo % 45) / 100, 2) # Probabilidad entre 0.30 y 0.74
p_exito_mejorada = min(p_exito * 1.20, 1.0)     # Aumento relativo del 20%

print(f"--- PARÁMETROS ÚNICOS DEL ANALISTA [{mi_codigo}] ---")
print(f"1. Binomial: n = {n_binom}, p = {p_exito}")
print(f"Escenario con tasa de éxito 20% mayor: p = {p_exito_mejorada:.3f}")
print(f"Número esperado de entregas exitosas: {n_binom * p_exito:.2f}")
print(f"Número esperado con la tasa mejorada: {n_binom * p_exito_mejorada:.2f}")
Tareas a desarrollar a partir de tus parámetros únicos:
  1. Calcular la media teórica $\mu$ y la varianza $\sigma^2$ de tu distribución binomial usando binom.stats(n_binom, p_exito, moments='mv').
  2. Graficar en un panel la funcion de masa de probabilidad (PMF). Incluye leyenda, ejes rotulados, título con tu código estudiantil y marca o comenta los valores esperados.
  3. Incrementar en un 20% relativo la tasa de éxito original ($p_{\text{mejorada}} = 1.20p$, sin superar 1) y calcular la nueva distribución binomial manteniendo constante el tamaño del lote $n$.
  4. Calcular y comparar, para ambos escenarios, la probabilidad de alcanzar o superar una misma meta operativa; interpreta cómo cambia el resultado para la planta.
