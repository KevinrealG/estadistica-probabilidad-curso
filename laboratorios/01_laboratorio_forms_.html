Laboratorio 1: Uso de Microsoft Forms y análisis previo

Recolección y sistematización de datos cuantitativos y cualitativos para análisis exploratorio, utilizando herramientas digitales.

Competencias por desarrollar

  • Recolectar y sistematizar datos utilizando métodos adecuados para construir tablas de frecuencias y representaciones gráficas pertinentes según el tipo de variable.
  • Emplear herramientas digitales y software estadístico para realizar análisis exploratorios, aplicar modelos probabilísticos y comunicar hallazgos con argumentos cuantitativos sólidos.

Resultados de aprendizaje

  • Recolecto y organizo información cuantitativa y cualitativa de manera sistemática, utilizando instrumentos adecuados para construir bases de datos confiables en distintos contextos.
  • Analizo e interpreto datos univariados y bivariados mediante el uso de descriptores estadísticos, gráficos y modelos de regresión, para identificar patrones y tomar decisiones informadas.
  • Utilizo software especializado (Excel, Power BI, Statgraphics, Google Colab, Microsoft Forms y R) para resolver problemas estadísticos, comunicar resultados y sustentar decisiones con rigor y claridad.

Temáticas que se desarrollan en la práctica

  • Conceptos básicos en estadística: poblaciones, muestras, tipos de variables y escalas de medición.
  • Tablas de frecuencias para variables cualitativas: gráficos de barras y circulares en una y dos dimensiones.
  • Práctica de laboratorio: construcción de una base de datos sencilla utilizando Microsoft Excel.

Problema de aplicación

Los estudiantes ingresan a un formulario de Microsoft Forms creado previamente por el docente, con el fin de experimentar el proceso de recolección de datos en línea a partir de la información suministrada por sus compañeros. Posteriormente, los datos recolectados serán exportados a Excel para la construcción de una base de datos y su análisis exploratorio.

Procedimiento

Paso 1. Acceso al formulario

Ingresa al enlace de Microsoft Forms proporcionado por el docente y completa la información solicitada.

Paso 2. Análisis inmediato

Explora las respuestas recopiladas en Microsoft Forms, observando los gráficos automáticos generados por la plataforma y realizando una primera interpretación de los resultados.

Compromisos para entregar

  1. Crea un formulario con mínimo cinco (5) preguntas utilizando Microsoft Forms. Este formulario debe estar diseñado para recolectar información relevante para el análisis(estudio) estadístico.
  2. El formulario debe incluir una introducción clara y objetiva, con Titulo, descripción, objetivo, población objetivo
  3. Desarrolla el formulario con una estructura clara y coherente, asegurando que las preguntas sean comprensibles y no sesgadas
  4. Las preguntas deben estar relacionadas con el objetivo del estudio y recolectar información relevante de las variables de interés. Ejemplo: pregunta:¿Cuál es tu red social preferida?,variable: Red Social. Debes ser exhaustivo en la formulación de las preguntas, e incluir opciones de respuesta adecuadas y completas, ejemplo: Facebook, Instagram, Twitter, TikTok, Otras
  5. Si la variable es numérica, asegúrate de incluir escalas de medida apropiadas y los intervalos de medición.
  6. Solicita la participación de tus compañeros para diligenciar el formulario.
  7. Exporta las respuestas a Excel y genera al menos dos (2) gráficas correspondientes a las preguntas del formulario.
  8. Elabora un documento en Word que incluya:
    • Nombre de la experiencia
    • Enlace del formulario de Microsoft Forms
    • Dos gráficas con su respectiva interpretación
  9. Guarda el documento en formato PDF y súbelo al espacio asignado por el docente en la plataforma SAVIO.

Rúbrica de Evaluación

Ítem a evaluar Porcentaje

2. Recolección de datos (Participación de compañeros) 10%
3. Exportación a Excel y generación de gráficas 30%
4. Documento con enlace e interpretación analítica de las gráficas 30%
5. Formato (PDF) y entrega correcta en SAVIO 10%
