Competencias Por Desarrollar

  • Recolectar y sistematizar datos utilizando métodos adecuados para construir tablas de frecuencias y representaciones gráficas pertinentes según el tipo de variable.
  • Calcular e interpretar medidas estadísticas (de tendencia central, dispersión, posición y asociación) para describir y analizar conjuntos de datos univariados y bivariados.
  • Emplear herramientas digitales y software estadístico para realizar análisis exploratorios, aplicar modelos probabilísticos y comunicar hallazgos con argumentos cuantitativos sólidos.

Instrucciones del Laboratorio

En este laboratorio, aprenderás a cargar datos desde diferentes fuentes en Google Colab, incluyendo archivos CSV, Excel y datasets de Kaggle. Asegúrate de seguir los pasos cuidadosamente y documentar tu proceso.

Recuerda que es importante tener una cuenta de Google y acceso a Google Colab para completar este laboratorio. Además, necesitarás una cuenta en Kaggle para descargar datasets directamente desde la plataforma.

1. Carga de datos desde un archivo CSV

⬇️ Descargar Base de Datos 1 ⬇️ Descargar Base de Datos 2

Para cargar un archivo CSV local o desde tu Google Drive, utilizamos la librería Pandas:

import pandas as pd

# Cargar el archivo CSV
df_csv = pd.read_csv('ruta_del_archivo.csv')

# Análisis breve
df_csv.head()
df_csv.info()

2. Carga de datos desde un archivo Excel

La lectura de archivos Excel requiere especificar el nombre de la hoja si el documento tiene varias:

# Cargar el archivo Excel
df_excel = pd.read_excel('ruta_del_archivo.xlsx', sheet_name='Hoja1')

# Resumen estadístico básico
df_excel.describe()

3. Carga de datos desde Google Drive

Para acceder a archivos almacenados en Google Drive, primero montamos el drive en Colab y montamos los archivos a drive en su carpeta correspondiente:

from google.colab import drive
# Montar Google Drive
drive.mount('/content/drive')
# Cargar archivo desde Google Drive
df_drive = pd.read_csv('/content/drive/MyDrive/ruta_del_archivo.csv')
# Análisis exploratorio
df_drive.head()

4. Carga de datos usando la API de Kaggle

Para descargar datasets directamente desde Kaggle(link: Link al dataset), primero debes tener cuenta en Kaggle:

# Subir el archivo kaggle.json
# Install dependencies as needed:
# pip install kagglehub[pandas-datasets]
import kagglehub
from kagglehub import KaggleDatasetAdapter

# Set the path to the file you'd like to load
file_path = ""

# Load the latest version
df = kagglehub.load_dataset(
  KaggleDatasetAdapter.PANDAS,
  "danielsowah123/retail-sales-dataset",
  file_path,
  # Provide any additional arguments like 
  # sql_query or pandas_kwargs. See the 
  # documenation for more information:
  # https://github.com/Kaggle/kagglehub/blob/main/README.md#kaggledatasetadapterpandas
)

print("First 5 records:", df.head())
