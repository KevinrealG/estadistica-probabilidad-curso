Instrucciones del Laboratorio

1. Carga de datos desde un archivo CSV

Para cargar un archivo CSV local o desde tu Google Drive, utilizamos la librería Pandas:

import pandas as pd

# Cargar el archivo CSV
df_csv = pd.read_csv('ruta_del_archivo.csv')

# Análisis breve
df_csv.head()
df_csv.info()

2. Carga de datos desde un archivo Excel

La lectura de archivos Excel requiere especificar el nombre de la hoja si el documento tiene varias:

# Cargar el archivo Excel
df_excel = pd.read_excel('ruta_del_archivo.xlsx', sheet_name='Hoja1')

# Resumen estadístico básico
df_excel.describe()

3. Carga de datos usando la API de Kaggle

Para descargar datasets directamente desde Kaggle, primero debes subir tu archivo kaggle.json (token de API) a Colab:

# Subir el archivo kaggle.json
from google.colab import files
files.upload()

# Crear el directorio y configurar permisos
!mkdir -p ~/.kaggle
!cp kaggle.json ~/.kaggle/
!chmod 600 ~/.kaggle/kaggle.json

# Descargar y descomprimir el dataset
!kaggle datasets download -d nombre-del-usuario/nombre-del-dataset
!unzip nombre-del-dataset.zip
