Introducción

Este laboratorio se enfoca en el uso de herramientas computacionales como Python, junto con las librerías NumPy y SymPy en el entorno de Google Colab, para representar y resolver sistemas de ecuaciones lineales aplicados a problemas en ciencias e ingeniería.

Objetivos

  • Configurar el entorno de trabajo en Google Colab para computación simbólica y numérica con Python.
  • Representar vectores, matrices y sistemas de ecuaciones lineales usando la librería SymPy.
  • Implementar los métodos de eliminación gaussiana y Gauss-Jordan para resolver sistemas de ecuaciones.
  • Aplicar estos métodos a un problema de aplicación asignado y elaborar conclusiones.

Desarrollo del Laboratorio

Defina la matriz de coeficientes A y el vector b de su problema asignado. Construya la matriz aumentada [A|b] y realice extracciones de filas y columnas.

Cree variables simbólicas mediante sp.symbols() y formule el sistema usando sp.Eq().

Realice operaciones elementales de fila paso a paso. Posteriormente, aplique Aug.rref() para encontrar la forma escalonada reducida y sp.linsolve() para la solución.

Resuelva exclusivamente el problema asignado (1 al 8) según su número (ej: Redes eléctricas, Equilibrio de mercado, Balanceo químico, etc.).

Código Python - Configuración

# Instalacion de librerias
!pip install sympy numpy matplotlib

import sympy as sp
import numpy as np

# Configurar para impresión bonita
sp.init_printing(use_unicode=True)

# Ejemplo de Matriz Aumentada y Solución
A = sp.Matrix([[10, -2, -3], [-2, 8, 1], [-3, -1, 6]])
b = sp.Matrix([5, 3, 4])
Aug = A.row_join(b)

sol = sp.linsolve(Aug, sp.symbols('i1 i2 i3'))
sp.pprint(sol)
