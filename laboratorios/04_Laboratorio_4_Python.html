Competencias Por Desarrollar

  • Recolectar y sistematizar datos utilizando métodos adecuados para construir tablas de frecuencias y representaciones gráficas pertinentes según el tipo de variable.
  • Calcular e interpretar medidas estadísticas (de tendencia central, dispersión, posición y asociación) para describir y analizar conjuntos de datos univariados y bivariados.
  • Emplear herramientas digitales y software estadístico para realizar análisis exploratorios, aplicar modelos probabilísticos y comunicar hallazgos con argumentos cuantitativos sólidos.

Resultados de Aprendizaje

  • Recolecto y organizo información cuantitativa y cualitativa de manera sistemática, utilizando instrumentos adecuados para construir bases de datos confiables en distintos contextos.
  • Analizo e interpreto datos univariados y bivariados mediante el uso de descriptores estadísticos, gráficos y modelos de regresión, para identificar patrones y tomar decisiones informadas.
  • Utilizo software especializado (Excel, Power BI, Statgraphics, Google Colab, Google Form y R) para resolver problemas estadísticos, comunicar resultados y sustentar decisiones con rigor y claridad.

Temáticas trabajadas en esta práctica

  • Análisis Exploratorio de Datos (EDA) en Python usando Colab
  • Carga, limpieza y organización básica de datos
  • Generación de nuevas columnas mediante transformación de variables
  • Uso de librerías como Pandas, NumPy y Matplotlib
  • Resumen estadístico y visualización inicial para exploración

Problema de aplicación

Los estudiantes usarán los datos publicados en la plataforma SAVIO y, haciendo uso de Python en Google Colab, realizarán un Análisis Exploratorio de Datos (EDA) siguiendo paso a paso el procedimiento explicado en el video de la Semana 8.

El objetivo es comprender la estructura del dataset, calcular medidas descriptivas, explorar relaciones entre variables y agregar columnas derivadas que permitan enriquecer el análisis.

✅ Rúbrica de Evaluación

Criterio Nivel 1 – Insuficiente Nivel 2 – Aceptable Nivel 3 – Bueno Nivel 4 – Excelente
1. Carga y organización de datos en Colab No logra importar los datos o no presenta evidencia clara. Importación incompleta o visualización limitada; poca claridad en la organización. Importa y visualiza los datos de forma adecuada, con leves omisiones no críticas. Importa los datos correctamente, visualiza las primeras filas, analiza tipos de variables y muestra organización impecable del DataFrame.
2. Código y desarrollo del Análisis Exploratorio (EDA) No incluye el código o no funciona. El código presenta errores significativos o análisis incompleto. El código funciona con pequeñas omisiones o errores menores. La exploración es adecuada. El código está completo, funcional, bien organizado y utiliza correctamente Pandas/NumPy. Se incluye estadística descriptiva, transformaciones y verificaciones.
3. Visualizaciones generadas No incluye visualizaciones o son incorrectas. Visualizaciones incompletas, básicas o sin etiquetas adecuadas. Gráficos correctos pero con detalles menores en forma o interpretación. Los gráficos son claros, pertinentes y bien etiquetados. Se incluyen distribuciones, resúmenes visuales y conclusiones derivadas.
4. Creación de una nueva columna y análisis adicional No crea una nueva columna. Crea la columna con errores o sin justificación. Crea la columna, aunque con explicación mínima o poco análisis. Crea una columna nueva correctamente, explica su propósito y analiza su impacto en el DataFrame.
5. Presentación y entrega (PDF guiado + PDF autónomo) No entrega los documentos o la evidencia es insuficiente. Solo entrega uno de los PDFs o archivos incompletos. Entrega ambos PDFs con pequeños problemas de organización o formato. Entrega ambos PDFs completos, bien organizados, con código, gráficos y conclusiones relacionadas con competencias y temas del laboratorio.
