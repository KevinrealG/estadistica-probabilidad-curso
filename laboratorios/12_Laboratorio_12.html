Temáticas que se desarrollan en esta práctica

  • Variable aleatoria continua: puede tomar cualquier valor dentro de un intervalo; en esta práctica, el volumen de llenado medido en mililitros. Las probabilidades se calculan para intervalos: la probabilidad de un valor exacto es cero.
  • Función de Densidad de Probabilidad (PDF): describe cómo se distribuyen los valores posibles. El área total bajo la curva es 1 y el área entre dos valores representa la probabilidad de que la variable esté en ese intervalo; la altura de la curva en un punto no es, por sí sola, una probabilidad.
  • Distribución Normal $N(\mu, \sigma)$: simetría, centro y dispersión.
  • Regla Empírica ($68\text{–}95\text{–}99.7\%$): en una distribución aproximadamente normal, cerca del $68\%$, $95\%$ y $99.7\%$ de los datos se encuentran, respectivamente, dentro de los intervalos $\mu \pm \sigma$, $\mu \pm 2\sigma$ y $\mu \pm 3\sigma$.
  • Simulación computacional e histogramas con densidad superpuesta en Python.
  • Análisis de sensibilidad modificando $\mu$ (traslación) y $\sigma$ (escalamiento).

Problema de aplicación

"Control de Precisión en Dosificación Industrial"

Continúas tu auditoría pasando al área de llenado automatizado de un compuesto líquido de alta precisión. A diferencia del conteo de paquetes (discreto), el volumen de llenado en mililitros es una variable aleatoria continua que sigue una Distribución Normal.

Cada estudiante auditará un reactor calibrado con una media $\mu$ y una desviación estándar $\sigma$ generadas únicamente por su código estudiantil. Tu misión es simular $1,000$ mediciones del reactor, comprobar si cumple con la Regla Empírica ($68\text{–}95\text{–}99.7$) y evaluar qué sucede con la curva de densidad si el reactor sufre un desajuste térmico (aumento de $\sigma$).

Código base para el estudiante

import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy.stats import norm

# ==========================================================
# PASO CRÍTICO: INGRESA LOS ÚLTIMOS 4 DÍGITOS DE TU CÓDIGO
# ==========================================================
mi_codigo = 4829  # <-- Reemplaza con tus últimos 4 dígitos
np.random.seed(mi_codigo)

# Parámetros únicos de tu reactor industrial (en mililitros)
mu = 250 + (mi_codigo % 50)          # Media entre 250 y 299 ml
sigma = round(4 + (mi_codigo % 11) * 0.5, 1) # Desviación entre 4.0 y 9.0 ml

# 1. Simulación de 1,000 mediciones continuas
datos_simulados = np.random.normal(loc=mu, scale=sigma, size=1000)
media_muestral = np.mean(datos_simulados)
sigma_muestral = np.std(datos_simulados, ddof=1)

# Gráficos exploratorios: histograma con KDE y diagrama de caja
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

sns.histplot(datos_simulados, bins=30, kde=True, color='skyblue', edgecolor='black', ax=axes[0])
axes[0].axvline(mu, color='navy', linestyle='--', linewidth=2, label=f'Media: {mu} ml')
axes[0].set_title('Histograma de Volumen de Llenado')
axes[0].set_xlabel('Volumen (ml)')
axes[0].set_ylabel('Frecuencia')
axes[0].legend()
axes[0].grid(alpha=0.3)

sns.boxplot(x=datos_simulados, color='lightgreen', ax=axes[1])
axes[1].axvline(mu, color='navy', linestyle='--', linewidth=2, label=f'Media: {mu} ml')
axes[1].set_title('Boxplot de Volumen de Llenado')
axes[1].set_xlabel('Volumen (ml)')
axes[1].legend()
axes[1].grid(alpha=0.3)

plt.tight_layout()
plt.show()

# 2. Verificación de la Regla Empírica (68 - 95 - 99.7) en tu muestra
dentro_1sigma = np.mean((datos_simulados >= mu - sigma) & (datos_simulados <= mu + sigma)) * 100
dentro_2sigma = np.mean((datos_simulados >= mu - 2*sigma) & (datos_simulados <= mu + 2*sigma)) * 100
dentro_3sigma = np.mean((datos_simulados >= mu - 3*sigma) & (datos_simulados <= mu + 3*sigma)) * 100

print(f"--- AUDITORÍA NORMAL DEL ANALISTA [{mi_codigo}] ---")
print(f"Parámetros Teóricos: Media (mu) = {mu} ml | Desviación (sigma) = {sigma} ml")
print(f"Parámetros Muestrales: Media = {media_muestral:.2f} ml | Desviación = {sigma_muestral:.2f} ml")
print(f"Regla Empírica Simulada: 1s = {dentro_1sigma:.1f}% | 2s = {dentro_2sigma:.1f}% | 3s = {dentro_3sigma:.1f}%")

# 3. Gráfico: Histograma Empírico + Curva de Densidad Teórica (PDF)
x = np.linspace(mu - 4*sigma, mu + 4*sigma, 200)
plt.figure(figsize=(8, 4))
plt.hist(datos_simulados, bins=30, density=True, alpha=0.6, color='skyblue', edgecolor='black', label='Simulación (n=1000)')
plt.plot(x, norm.pdf(x, mu, sigma), 'r-', lw=2.5, label=f'PDF Teórica N({mu}, {sigma})')
plt.axvline(mu, color='navy', linestyle='--', label='Media')
plt.axvline(mu - sigma, color='gray', linestyle=':', label='Media ± 1σ')
plt.axvline(mu + sigma, color='gray', linestyle=':')
plt.title(f'Distribución Normal de Llenado - Analista {mi_codigo}')
plt.xlabel('Volumen (ml)')
plt.ylabel('Densidad de Probabilidad')
plt.legend()
plt.grid(alpha=0.3)
plt.show()

# 4. Sensibilidad: desfase de la media y pérdida de precisión
x_sens = np.linspace(mu - 8*sigma, mu + 15 + 8*sigma, 400)
plt.figure(figsize=(8, 4))
plt.plot(x_sens, norm.pdf(x_sens, mu, sigma), lw=2.5, label='Base')
plt.plot(x_sens, norm.pdf(x_sens, mu + 15, sigma), lw=2, label='Desfase: mu + 15')
plt.plot(x_sens, norm.pdf(x_sens, mu, 2*sigma), lw=2, label='Menor precisión: 2 sigma')
plt.title('Análisis de sensibilidad de la distribución normal')
plt.xlabel('Volumen (ml)')
plt.ylabel('Densidad de Probabilidad')
plt.legend()
plt.grid(alpha=0.3)
plt.show()
