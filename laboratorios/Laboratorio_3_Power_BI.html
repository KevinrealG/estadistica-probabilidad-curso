Competencias por desarrollar

  • Recolectar y sistematizar datos utilizando métodos adecuados para construir tablas de frecuencias y representaciones gráficas pertinentes según el tipo de variable.
  • Calcular e interpretar medidas estadísticas (de tendencia central, dispersión, posición y asociación) para describir y analizar conjuntos de datos univariados y bivariados.
  • Emplear herramientas digitales y software estadístico para realizar análisis exploratorios, aplicar modelos probabilísticos y comunicar hallazgos con argumentos cuantitativos sólidos.

Resultados de aprendizaje

  • Recolecto y organizo información cuantitativa y cualitativa de manera sistemática, utilizando instrumentos adecuados para construir bases de datos confiables en distintos contextos.
  • Analizo e interpreto datos univariados y bivariados mediante el uso de descriptores estadísticos, gráficos y modelos de regresión, para identificar patrones y tomar decisiones informadas.
  • Utilizo software especializado (Excel, Power BI, Statgraphics, Google Colab, Google Form y R) para resolver problemas estadísticos, comunicar resultados y sustentar decisiones con rigor y claridad.

Material de Trabajo

Archivo base para la práctica: Inmuebles2.xlsx

(El archivo contiene datos de inmuebles con múltiples variables cualitativas y cuantitativas para realizar limpieza y análisis.)

⬇️ Descargar Inmuebles2.xlsx

Temáticas que se desarrollan en la práctica

  • Tablas de frecuencias para variables cualitativas Bivariadas.
  • Práctica de laboratorios: Una pequeña limpieza de Datos en Power BI.

Problema de aplicación

Los estudiantes utilizarán el archivo Inmuebles2.xlsx, el cual ya se encuentra cargado en la plataforma SAVIO. A partir de este archivo deberán:

  • Cargar los datos en Power BI desde Excel.
  • Realizar una limpieza básica de datos, siguiendo exactamente las instrucciones explicadas en el video de Semana 5.
  • Generar una tabla de frecuencias bivariada entre dos variables elegidas por el estudiante.
  • Exportar el resultado como archivo PDF.

Compromisos de entrega

📌 Entregable 1 — Reproducción de la experiencia del laboratorio

Debe incluir:

  • Limpieza de datos aplicada al archivo Inmuebles2.xlsx.
  • Con los datos limpios debe generar por lo menos 3 gráficos o tablas en Power BI (Tabla de Frecuencia, Gráfico de Barras univariado, Gráfico de Barras Bivariado o Diagrama de Pastel).
  • Añadir una pequeña interpretación.
  • Exportación del informe de Power BI en formato PDF.

· Sube el archivo en el espacio creado por tu docente en SAVIO.

Rúbrica de Evaluación

2. Generación de al menos 3 gráficos/tablas pertinentes 30%
3. Calidad y coherencia de la interpretación de los datos 20%
4. Exportación a PDF y entrega oportuna en SAVIO 20%
