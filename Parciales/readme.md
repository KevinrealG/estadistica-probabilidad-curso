# Semillero de Estadística Aplicada - UTB

## 📊 Descripción

Repositorio oficial del Semillero de Estadística Aplicada de la Universidad Tecnológica de Bolívar (UTB). Espacio colaborativo dedicado a la investigación, desarrollo y aplicación de metodologías estadísticas en problemas reales.

## 🎯 Objetivos

- Fortalecer competencias en análisis estadístico aplicado
- Desarrollar proyectos de investigación con datos reales
- Fomentar el pensamiento crítico y científico
- Capacitar en herramientas computacionales para análisis de datos

## 📚 Contenido

- **Proyectos**: Investigaciones desarrolladas por los semilleristas
- **Tutoriales**: Guías de herramientas y métodos estadísticos
- **Datasets**: Conjuntos de datos para análisis y práctica
- **Código**: Scripts y notebooks con ejemplos prácticos
- **Documentación**: Reportes y publicaciones

## 🛠️ Tecnologías

- Python (pandas, NumPy, scikit-learn, matplotlib)
- R (ggplot2, tidyverse, Shiny)
- SQL
- Jupyter Notebooks
- Git & GitHub
